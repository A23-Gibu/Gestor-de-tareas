\# Gestor de Tareas



Aplicación de consola desarrollada en Java para gestionar tareas.



\## Requisitos

\- Java 17 o superior.

\- Maven 3.8 o superior.



\## Funcionalidades

\- Añadir tareas.

\- Mostrar tareas.

\- Completar tareas.

\- Eliminar tareas.



\## Tecnologías utilizadas

\- Java

\- Maven
